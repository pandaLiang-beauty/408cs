# 交卷后复盘批注

交卷后，试卷右侧显示「复盘批注」边栏。真题、模拟题和强化练习均可使用。

从首页进入：点击日历中绿色已完成卡片上的「复盘批注」（手机端显示「复盘」），直接打开那次作答。今日任务完成后也会显示「复盘批注」按钮。

1. 选中题干、选项或解析中的文字，点击浮动的「添加批注」。
2. 在边栏填写疑问、解题思路或易错点，点击「保存批注」，也可按 Ctrl / ⌘ + Enter。
3. 点击批注引用的原文，可自动翻页并定位；解析处的批注会展开对应解析。

题号旁的「批注」可记录整题想法，适合图片、图表或不便选中文字的内容。批注支持编辑、删除、标为已解决和重新打开；手机端在底部面板编辑。

## 作答记录与保存

- 每条批注属于一次作答中的一道题。重新做同一年真题会产生独立记录，旧批注仍留在旧记录中。
- 试卷地址中的 `sid` 标识该次作答；再次打开相同地址，可以继续查看这次作答、成绩与批注。
- 批注保存在数据库中，不修改原作答、成绩、草稿或已有笔记。
- 尚未保存的批注草稿按作答记录暂存在当前浏览器中；保存失败后可重试，刷新也能恢复。保存成功后才可跨设备查看。
- 批注只在整卷交卷后开放，做题时不显示入口。

## 实现与验证

`annotations` 表通过 `session_item_id` 关联本次作答，初始化时增量建表，不重建原有学习数据。文字锚点记录题干/选项/解析区域、选中文字、UTF-16 偏移和前后文；原文无法匹配时仍保留批注，并定位到对应题目。

后端回归测试见 `backend/test_annotations.py`；文字定位测试见 `frontend/src/utils/annotationAnchors.test.js`。浏览器验证覆盖交卷前后的入口切换、不同作答的批注隔离、刷新恢复、跨页定位、网络失败重试和手机布局。
